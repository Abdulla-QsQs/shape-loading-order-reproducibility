# Feedback-coefficient calibration status

The locked publication coefficient is beta = 250, as recorded in
`config/publication_study.json` and in each run metadata record. The study
protocol records that beta was selected from design-stage pilot
selection-entropy behaviour rather than from a final mechanical outcome.

A separate pilot calibration log or entropy sweep was not present in the
retained project records searched for this release. This package therefore
reproduces the final publication ensemble conditional on the locked value
beta = 250, while treating the pilot-selection artefact as unavailable
provenance rather than inventing a calibration record.
