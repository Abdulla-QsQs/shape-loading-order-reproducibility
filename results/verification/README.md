# Mesh-verification subset

This directory retains only the five completed two-cycle, fixed-order, 1 MN
benchmarks used for the publication mesh trend (resolutions 4 through 8).

The resolution-4 source run was originally named `force1000`; it is normalized
here to `mesh4_force1000`. The first resolution-7 attempt failed during
calibration and is excluded; the unchanged successful rerun originally named
`mesh7_force1000b` is normalized here to `mesh7_force1000`. Original run IDs
remain visible inside the metadata and CSV rows. No numerical values were edited.
