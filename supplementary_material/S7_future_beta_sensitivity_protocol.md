# S7. Prospective beta-sensitivity extension

This is a future-study protocol and is not evidence for the current 36-run ensemble.

Before generating new mechanical outcomes, a follow-up should freeze a beta grid that includes `beta = 0` as a uniform-selection negative control and values below and above 250. A candidate grid is 0, 125, 250, 500, and 1000, subject to being fixed before examining the new outcomes. The same direction pools, force schedule, geometry, material law, solver criteria, and designated endpoints should be retained. New independent pools and multiple policy realizations per pool should be used so beta response is not confused with one stochastic ordering realization.

The extension should report selector entropy, maximum probability, effective candidate count, final shape anisotropy, independent geometry outcomes, and internal-field outcomes. The beta-response analysis must remain separate from the locked publication ensemble and must not be used to redefine the original primary result.
